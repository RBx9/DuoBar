# DuoBar v0.2.1 — RootHide

**Stable update** for iOS 16.x with Dopamine RootHide.

## What's new

- Fixed duplicate stock battery percentage in Control Center.
- Fixed the rotation-lock icon overlapping DuoBar in the expanded Control Center status area.
- Added the approved blue DuoBar icon to iOS Settings and the preference-page header.
- Organized **Settings → DuoBar** into **Appearance**, **About DuoBar**, and **Links & Updates**.
- Added **RBx9 Repo**, **Add Source to Sileo**, GitHub, and Twitter / X links.
- Kept the Enable DuoBar preference and live stock-icon restoration.

## Install / update

**Recommended:** Open **Sileo → Sources → RBx9 Repo** (`https://rbx9.github.io/`) and upgrade **DuoBar (RootHide)**. Respring after installation.

**Manual:** Download `DuoBar_0.2.1_RootHide.deb`, install using a RootHide-compatible package manager, then respring.

Package: `local.duobar` · Version: `0.2.1` · Architecture: `iphoneos-arm64e`.

Control Center fixes were tested successfully on-device. The new Settings icon and links are compiled but need a final on-device visual check. For rollback, [v0.2.0](https://github.com/RBx9/DuoBar/releases/tag/v0.2.0) remains available.
