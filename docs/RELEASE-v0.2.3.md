# DuoBar v0.2.3 — Adjustable Size

**Stable RootHide update** for iOS 16.x with Dopamine RootHide.

## What's new

- New **DuoBar Size** slider in Settings, adjustable from **70% to 140%** in 5% increments.
- Displays the selected **Current Size** percentage.
- **Reset Size to 100%** restores the original appearance.
- The glyph resizes without a respring and remembers your setting.
- Previous Control Center overlap fixes, charging/Low Power Mode colors, and the custom Settings icon are preserved.

## Install

In **Sileo**, refresh **RBx9 Repo** at `https://rbx9.github.io/`, open **DuoBar (RootHide)**, and upgrade to **v0.2.3**. Respring once after the package upgrade.

Or install the attached `DuoBar_0.2.3_RootHide.deb` manually using a RootHide-compatible package manager.

Package ID: `local.duobar` · Version: `0.2.3` · Architecture: `iphoneos-arm64e`.

The beta was tested and approved before this stable release. Very large sizes may be limited by compact status-bar layouts.
