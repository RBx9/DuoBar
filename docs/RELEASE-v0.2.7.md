## What's New

- **Improvements** to the settings experience and overall polish.
- Keeps the circular battery percentage, Wi-Fi and cellular indicator, hotspot support, Control Center fixes and adjustable size.

## Install / upgrade

In Sileo, refresh **RBx9 Repo**: `https://rbx9.github.io/`. Select **DuoBar (RootHide)** or **DuoBar (Rootless)** according to your jailbreak, upgrade, and respring.

Both builds have separate verified package metadata, architecture and installation-path checks. **Rootless runtime compatibility still requires testing on a real Rootless iPhone.** Do not install both editions together.
