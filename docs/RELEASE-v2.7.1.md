# DuoBar v2.7.1 — RootHide + Rootless

**Same DuoBar features, new version number.** This release uses **2.7.1** instead of the previous **0.2.7** version scheme.

DuoBar combines a live battery percentage, Wi-Fi, and cellular signals into one compact circular status-bar indicator, with adjustable size (70–140%), charging and Low Power Mode colors, Personal Hotspot support, Control Center fixes, and convenient Settings options.

## Install / upgrade

In **Sileo**, refresh **RBx9 Repo** (`https://rbx9.github.io/`) and choose the package matching your jailbreak:

| iOS 16 jailbreak | Package | Architecture | Installer |
| --- | --- | --- | --- |
| **Dopamine RootHide** | `local.duobar` | `iphoneos-arm64e` | [RootHide .deb](https://github.com/RBx9/DuoBar/releases/download/v2.7.1/DuoBar_2.7.1_RootHide.deb) |
| **Standard Dopamine Rootless** | `local.duobar.rootless` | `iphoneos-arm64` | [Rootless .deb](https://github.com/RBx9/DuoBar/releases/download/v2.7.1/DuoBar_2.7.1_Rootless.deb) |

Respring after installation. The two editions have distinct package IDs and undergo separate architecture and file-layout checks. **Standard Rootless still needs independent real-device verification.**

This release only updates the version number; it does not extend support to other iOS versions.
