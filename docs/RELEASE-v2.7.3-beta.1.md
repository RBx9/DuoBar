DuoBar 2.7.3 beta 1 is a test build for iOS 16, for Dopamine RootHide and standard Rootless (Dopamine, palera1n). It is not on Sileo yet. Stable 2.7.2 is unchanged.

## Fix

- **Control Center percentage in other languages:** iOS writes the battery percentage as "%33" in Turkish and "33 %" in French. DuoBar only hid "33%", so in those languages Control Center's percentage stayed visible and overlapped the ring. It is now hidden in every language. Reported on an iPhone 8 Plus with palera1n.

Everything else is the same as 2.7.2.

## Install

Download the `.deb` that matches your jailbreak (`RootHide` for Dopamine RootHide, `Rootless` for Dopamine Rootless or palera1n), open it in your package manager and respring.
