DuoBar 2.7.3 beta 3 is a test build for iOS 16, for Dopamine RootHide and standard Rootless (Dopamine, palera1n). It is not on Sileo. Stable 2.7.2 is unchanged.

## Fixes

- **Rotation-lock icon flickering in Control Center:** DuoBar now remembers the icon it moved aside instead of searching for it again on every layout pass, so it stays beside the ring.
- **Ring jumping sideways** while the red screen-recording bar is showing (beta 2): DuoBar stays at the battery's last position when a layout pass drops the battery.
- **Control Center percentage** in Turkish ("%33") and French ("33 %") is hidden (beta 1).

## Install

Download the `.deb` for your jailbreak (`Rootless` for Dopamine Rootless or palera1n, `RootHide` for Dopamine RootHide), open it in your package manager and respring.
