# DuoBar v0.2.6 Beta 1 — Settings Icon Polish

**Test build for iOS 16.x Dopamine RootHide. Not released through Sileo.**

## What's new

- Removed the white square surrounding the rounded DuoBar icon in the Settings tweak list.
- Refined the original blue icon using transparent corners in all installed display sizes.
- Preserved the working Personal Hotspot, Control Center positioning, no-flash transitions, and size slider from stable v0.2.5.

## Install and test

Install the attached `DuoBar_0.2.6-beta1_RootHide.deb` using your RootHide-compatible package manager, then respring and **fully close/reopen Settings** to clear cached tweak icons.

Check the DuoBar icon in the main Settings list under both light and dark appearance, then open **Settings → DuoBar** and confirm the page still behaves normally. Check the status bar and Control Center for regressions.

The icon fix is package-verified but needs on-device visual confirmation before a stable release.

**Rollback:** [DuoBar v0.2.5 stable](https://github.com/RBx9/DuoBar/releases/tag/v0.2.5).

Architecture: `iphoneos-arm64e` · Package: `local.duobar` · Version: `0.2.6~beta1`.
