# DuoBar v0.2.7 Beta 1 — Telegram Channel

**RootHide and standard Rootless test builds for iOS 16. Not yet published in Sileo.**

## What's new

- New **Telegram Channel: @RBx9_Repo** button under **Settings → DuoBar → Links & Updates**.
- Opens the official channel: https://t.me/RBx9_Repo.
- Keeps the working battery/Wi-Fi/cellular ring, Personal Hotspot link, Control Center fixes, transparent Settings icon, size slider, and existing Settings links unchanged.

## Install and test

Download **only** the file for your jailbreak and install it with a compatible package manager; then respring.

- **Dopamine RootHide:** `DuoBar_0.2.7-beta1_RootHide.deb` · `local.duobar` · `iphoneos-arm64e`
- **Standard Dopamine Rootless:** `DuoBar_0.2.7-beta1_Rootless.deb` · `local.duobar.rootless` · `iphoneos-arm64`

Open **Settings → DuoBar → Links & Updates → Telegram Channel: @RBx9_Repo**. Confirm it opens the correct channel, preferably in the Telegram app if installed. Check that the existing Sileo, GitHub, feedback and other Settings options still work.

Rootless has passed package verification in earlier releases but requires confirmation on a Rootless-jailbroken iPhone. A successful compilation alone does not prove full runtime compatibility.

**Rollback:** [RootHide / Rootless v0.2.6 stable](https://github.com/RBx9/DuoBar/releases/tag/v0.2.6).
